## 📖 关于这个仓库 | About

这是我的个人编程学习记录仓库。

创建这个仓库的初衷，是希望能够系统地保存自己在编程学习过程中的代码、笔记、实验以及解决问题的思路。

这里的每一份代码、每一次修改、每一条 Git Commit，都是我学习过程中的一部分。

这个仓库并不追求所有代码从一开始就完美，而是希望真实地记录从不熟悉到逐渐理解、从简单练习到独立完成项目的成长过程。

**Learning by doing. Growing through practice.**

## 🌱 我的学习原则 | Learning Philosophy

**1. Practice First — 实践优先**

通过亲手编写代码理解知识，而不仅仅停留在理论层面。

**2. Understand Why — 理解原理**

不仅关注代码如何运行，更关注为什么这样设计。

**3. Record Mistakes — 记录错误**

保留学习过程中遇到的问题和解决方案，因为错误也是成长的重要组成部分。

**4. Keep Improving — 持续改进**

允许早期代码不够完善，通过不断重构、优化和总结提升编程能力。

**5. Stay Consistent — 保持积累**

不追求每天都有巨大的进步，而是重视长期、稳定的学习与实践。

## 📌 关于提交记录 | Commit History

本仓库使用 Git 记录学习过程中的代码变化。

常用提交类型：

* `study:` 学习新知识与完成练习
* `feat:` 添加新功能
* `fix:` 修复程序问题
* `refactor:` 重构与优化代码
* `docs:` 更新笔记与文档
* `experiment:` 记录实验性代码

每一次 Commit，都是学习历程中的一个小小里程碑。
